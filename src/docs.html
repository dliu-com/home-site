How it works

dliu.com is a static site: a landing page, a 404 page, the docs pages and the résumé PDF. The files sit in a private S3 bucket and CloudFront delivers them. There are no servers, no database and no JavaScript.

0 serversonly static files
0 JavaScriptHTML and the shared CSS only
All edge locationsCloudFront, HTTP/2 and HTTP/3
1 CDK stackdliu-com in eu-west-1 (Ireland)
  • Pages. src/index.html, src/404.html, src/docs.html and src/docs-health.html, plus src/style.css for the landing page's layout. The header, footer, cards and colours come from the shared dliu.com stylesheets on files.dliu.com, so every dliu.com site looks the same.
  • Clean URLs. A viewer-request CloudFront Function serves / from index.html, /docs from docs.html and /docs/health from docs-health.html. Missing files return the 404 page.
  • Visitor statistics. A shared viewer-response function sets the anonymous dl_vid visitor cookie, and CloudFront's access logs feed traffic.dliu.com.
  • Résumé. Written in LaTeX (resume/resume.tex) and built with Tectonic by make resume into src/resume.pdf, which is served at /resume.pdf.
  • DNS. The dliu.com hosted zone belongs to the shared core infrastructure. This stack only adds the apex A and AAAA alias records.

Caching

FilesBrowserCloudFront edge
HTML pagesNo Cache-Control headerDefault caching, up to 1 day
style.css, resume.pdf5 minutes1 day (s-maxage=86400, stale-while-revalidate=86400)
Shared stylesheets and iconCached by files.dliu.com
  • Every deploy invalidates /* once, so changes show at the edge straight away. A browser may keep the old stylesheet or résumé for up to 5 minutes.
  • Automatic clearing on S3 changes is not used: the bucket only changes through deploys, which already clear the whole cache.

Deployment

The site is an AWS CDK app in cdk/. Deploys run locally from a machine with AWS credentials; there is no CI pipeline.

make install   # npm ci in cdk/
make test      # Jest: stack template and shared-look checks
make resume    # rebuild src/resume.pdf (only after résumé edits)
make deploy    # cdk deploy dliu-com

The deploy uploads src/ to the bucket in two steps: non-HTML files with the cache headers above, then the HTML files. Both invalidate the CloudFront cache.

Cost

Everything is billed per use, and at this site's traffic it stays inside the AWS free tiers: S3 storage for a few files, CloudFront requests and data transfer, and CloudFront Function invocations. The ACM certificate is free. The Route 53 hosted zone is shared with the other dliu.com sites.

Security

  • The S3 bucket blocks all public access. CloudFront reads it through an origin access identity, so files are only reachable through https://dliu.com.
  • HTTP requests are redirected to HTTPS. Only GET and HEAD are allowed.
  • There is no sign-in, form, API or JavaScript, and the site stores nothing about visitors apart from the anonymous visitor cookie used for traffic statistics.
